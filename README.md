# 📦 File Transfer Tool

A lightweight web tool for transferring files between devices using GitHub Gists. Requires a GitHub token.

## ✨ Features

- **GitHub Authentication** - Uses your GitHub token for private gists
- **Multiple Files** - Upload several files at once
- **Easy Retrieval** - Copy or download files instantly
- **Simple** - Paste content or upload files, get a transfer ID

## 🚀 How to Use

### Sending Files

1. Get a GitHub token with 'gist' scope from github.com/settings/tokens/new
2. Paste your token in the tool (saved in browser)
3. Paste text content OR upload files
4. Click "Create Transfer Link"
5. **Copy the Transfer ID**

### Receiving Files

1. Open the tool
2. Enter your GitHub token (if not already saved)
3. Paste the Transfer ID
4. Click "Retrieve Files"
5. Download or copy the content
